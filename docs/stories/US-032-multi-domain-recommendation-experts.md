# US-032 Multi-Domain Recommendation Experts

## Status

implemented

## Lane

normal

## Product Contract

AI recommendation demo data must include approved Expert accounts, profiles,
portfolios, proposal quota, and wallets across the six SoW demo domains so jobs
from each demo form can match multiple relevant experts.

## Relevant Product Docs

- `docs/ARCHITECTURE.md`
- `src/main/resources/db/migration/V44__seed_multi_domain_recommendation_experts.sql`

## Acceptance Criteria

- Seed data adds expert accounts and approved KYC profiles for API Testing,
  BI Dashboard, Computer Vision, Data Pipeline, Generic AI, and Chatbot/RAG.
- Each seeded Expert has a portfolio with domain, skill, technology, certificate,
  and self-description text that can be matched by recommendation keywords.
- Seeded Experts have proposal quota and wallet records for the post-recommend
  proposal flow.
- The migration does not seed saved `expert_recommendations`; recommendations
  remain generated by the service.

## Design Notes

- Commands: `docker compose up -d`; `.\mvnw.cmd test`
- Queries: seed verification is embedded in the migration `DO $$` block.
- API: recommendation endpoints under `/api/jobs/{jobPostingId}/expert-recommendations`.
- Tables: `account`, `expert_profiles`, `portfolios`, `user_quotas`,
  `quota_usage_logs`, `system_wallet`.
- Domain rules: demo Experts are approved and proposal-ready.
- UI surfaces: none.
