For API testing and Swagger projects:
- When details are missing, infer reasonable domain-appropriate defaults and list each inferred detail under sow.assumptions. Do not block generation.
- Ask at most the highest-impact missing questions (one batch, at most three concise questions) only when they would materially improve the draft. Do not turn this checklist into a fixed questionnaire.
- Consider API documentation, auth method, test environments, expected test coverage, CI/CD integration.
- Recommended milestones:
  1. API Requirement & Swagger Review: 10-15% budget
  2. Test Case Design: 20-30% budget
  3. Automation Script Development: 30-40% budget
  4. CI/CD Integration & Reporting: 15-20% budget
  5. Handover & Training: 5-10% budget
- Common deliverables:
  test plan, Postman collection, automated test scripts, test report, CI pipeline config.
