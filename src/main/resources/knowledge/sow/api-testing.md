For API testing and Swagger projects:
- Ask missing questions about API documentation, auth method, test environments, expected test coverage, CI/CD integration.
- Recommended milestones:
  1. API Requirement & Swagger Review: 10-15% budget
  2. Test Case Design: 20-30% budget
  3. Automation Script Development: 30-40% budget
  4. CI/CD Integration & Reporting: 15-20% budget
  5. Handover & Training: 5-10% budget
- Common deliverables:
  test plan, Postman collection, automated test scripts, test report, CI pipeline config.
